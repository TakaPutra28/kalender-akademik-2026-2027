# Kalender Akademik SDIT Yaa Bunayya TA 2026/2027

Repositori ini berisi dokumentasi lengkap, panduan, dan checklist untuk desain **Kalender Akademik SDIT Yaa Bunayya Tahun Ajaran 2026/2027** dalam format **A2 landscape** menggunakan **Canva**.

## 📋 Struktur Dokumentasi

- **[SPESIFIKASI_DESAIN.md](./SPESIFIKASI_DESAIN.md)** — Panduan desain lengkap (layout, warna, font, ukuran, margin)
- **[PANDUAN_CANVA.md](./PANDUAN_CANVA.md)** — Step-by-step implementasi di Canva (grouping, layer, elemen)
- **[PEMETAAN_AGENDA.md](./PEMETAAN_AGENDA.md)** — Daftar lengkap agenda per bulan dengan kategori warna
- **[CHECKLIST_KUALITAS.md](./CHECKLIST_KUALITAS.md)** — Quality control sebelum kirim ke percetakan
- **[PANDUAN_REVISI.md](./PANDUAN_REVISI.md)** — Cara edit & revisi aman tanpa merusak grid

## 🎨 Ringkasan Desain

**Format & Ukuran:**
- Ukuran: A2 (59,4 × 42 cm) landscape
- Bleed: 0,3 cm semua sisi
- Safe margin: 1,2 cm dari tepi trim

**Tiga Zona Utama:**
1. **Header Band** (6,0 cm) — Logo, judul, tahun ajaran
2. **Grid Kalender** (24,4 cm) — 12 blok bulan (4 kolom × 3 baris)
3. **Footer Band** (8,4 cm) — Legenda warna, kontak, QR code, catatan penting

**Palet Warna Brand:**
- Hijau Tua (#1F5C46) — Primary
- Tosca (#1E8C8A) — Secondary
- Emas (#C9A227) — Accent
- Krem (#FCFBF7) — Background

**12 Kategori Agenda dengan Warna:**
1. PBM — Hijau (#2F6E4E)
2. Libur — Merah (#B7402C)
3. Ujian — Biru (#2C5F9E)
4. Tahfizh — Ungu (#6A4C93)
5. Outing — Oranye (#E07A29)
6. Kajian — Tosca (#1E8C8A)
7. Administrasi — Abu (#8A8D91)
8. Ekstrakurikuler — Kuning (#F2C230)
9. Remedial — Coklat (#8B5E3C)
10. Classmeeting — Merah Muda (#E28FA0)
11. Laporan (Rapor) — Biru Tua (#16324F)
12. Kelulusan — Emas (#C9A227)

## 🔧 Alur Kerja

1. **Fase 1:** Baca [SPESIFIKASI_DESAIN.md](./SPESIFIKASI_DESAIN.md) untuk memahami layout & visual hierarchy
2. **Fase 2:** Ikuti [PANDUAN_CANVA.md](./PANDUAN_CANVA.md) untuk setup di Canva (create canvas, grouping layer, elemen dasar)
3. **Fase 3:** Gunakan [PEMETAAN_AGENDA.md](./PEMETAAN_AGENDA.md) untuk input tanggal & dot kategori
4. **Fase 4:** Jalankan [CHECKLIST_KUALITAS.md](./CHECKLIST_KUALITAS.md) sebelum export & cetak
5. **Fase 5:** Untuk revisi di masa depan, lihat [PANDUAN_REVISI.md](./PANDUAN_REVISI.md)

## 📦 Resource Canva

### Font (Gratis di Canva)
- **Poppins** — H1/H2/H3 judul
- **Nunito** — Label hari & angka tanggal
- **Lato** — Body text, legenda, kontak

### Elemen Canva (Cari di Elements)
- Pola geometris Islami: `islamic geometric pattern line`, `arabesque frame minimalist`
- Garis emas: `gold divider line elegant`
- Ikon: `graduation cap line icon`, `book open line icon`, dll
- Frame logo: `circle frame minimal`, `logo placeholder frame`
